# Changelog

## 1.0.0 (2026-10-02)

First release.

- New question type "Essay (word count)", based on the core Essay question.
- Adds a "Plain text, with word count" response format with a live word counter.
- Counter shows word limits (if set) and flags answers below the minimum or over the maximum.
- Word count is always shown to graders on review and manual grading screens.
- Supports Moodle XML import/export, backup/restore and the privacy API.
